# Coding Prompt Guidelines

Khi được kích hoạt để thực hiện tính năng mới:
1. Đọc kĩ requirements và plan trong `.gemini/scratch/plan.md`.
2. Đảm bảo tuân thủ kiến trúc hiện tại của dự án.
3. Không làm thay đổi signature của các API công khai trừ khi được yêu cầu.
4. Viết code sạch, tự tạo test case bao phủ các trường hợp biên (edge cases).
